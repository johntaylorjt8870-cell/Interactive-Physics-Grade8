# لقطات فحص المتصفح الحقيقي — الوحدة الثانية · الدرس 3 (فرق الكمون الكهربائي)

ناتجة عن `scripts/qa-unit2-lesson3.mjs` (Chromium 131 headless عبر playwright-core + @sparticuz/chromium مثبتتين خارج المستودع) على بناء `dist/` الإنتاجي، عند ثلاثة مقاسات: 1366×768 و1440×900 و390×844.

- **النتيجة:** 240 فحصاً، بلا فشل، وبلا أخطاء وحدة تحكم أو شبكة (تفاصيلها في `browser-results.json`).
- **التغطية:** تحميل الصفحة، تنقّل المحطات وشريط التقدم، إقفال الحلول قبل المحاولة، رفض التحقق الناقص، إجابات خاطئة مع تلميحات لا تكشف المفاتيح، مختبرات ص100–102 الحية (قاطعة، قراءات المقاييس، تسجيل U/U₁/U₂، علاقة التسلسل/التفرع، إعادة الضبط)، أنشطة ص102/103 العددية، فراغات ص106 (صياغات مكافئة مقبولة)، محوّل الوحدات، تشبيه الماء، التدريب السريع بلا كشف إجابات، بوابة المعلم (رفض كلمة خاطئة، دخول بكلمة المرور المعتمدة، عشر مقالات صفحات)، وإقلاع اختبار الدرس.

إعادة التشغيل:

```bash
npm run build
python3 -m http.server 4173 --bind 0.0.0.0 --directory dist
QA_MODULE_DIR=/path/to/qa/node_modules node scripts/qa-unit2-lesson3.mjs
```

# لقطات فحص المتصفح الحقيقي — الوحدة الثانية · الدرس 3 (فرق الكمون الكهربائي)

ناتجة عن `scripts/qa-unit2-lesson3.mjs` (Chromium 153 headless عبر playwright-core + @sparticuz/chromium مثبتتين خارج المستودع) على بناء `dist/` الإنتاجي، عند ثلاثة مقاسات: 1366×768 و1440×900 و390×844.

- **النتيجة:** 876 فحصاً (292 لكل مقاس)، بلا فشل، وبلا أخطاء وحدة تحكم أو شبكة (تفاصيلها في `browser-results.json`).
- **بنية الدرس المتحقَّق منها:** عشرة أزرار في قائمة الخطوات، خطوة واحدة فقط داخل `#page-content` في كل مرة (`data-page-view` واحد)، عنوان رئيسي ورقم صفحة كتاب مطابقان للصفحة المعروضة، نص الكتاب المعروض كله من الصفحة نفسها (`data-book-copy` واحد أو أكثر بنفس الرقم)، مؤشر تقدّم `x / 10` ونسبة الشريط و`aria-valuenow` ومركز التحكم «الخطوة x من 10 · صفحة y» متسقة، وتعطيل «السابق» في الخطوة الأولى و«التالي» في الأخيرة، والتنقل بـ `PageDown`/`PageUp`، والقفز من القائمة، والعودة عبر «السابق» حتى البداية.
- **التغطية التفاعلية:** الإجابة المحفوظة والنتيجة المحفوظة بعد مغادرة الخطوة والعودة إليها؛ إقفال الحلول قبل المحاولة؛ رفض التحقق الناقص؛ إجابات خاطئة مع تلميحات لا تكشف المفاتيح؛ مختبرات ص100–102 الحية (قاطعة، قراءات المقاييس، تسجيل U/U₁/U₂، علاقة التسلسل/التفرع، إعادة الضبط)؛ أنشطة ص102/103 العددية؛ فراغات ص106 (صياغات مكافئة مقبولة)؛ محوّل الوحدات؛ تشبيه الماء؛ التدريب السريع بلا كشف إجابات؛ وعدم تأثر نتيجة نشاط بخطوة أخرى.
- **عدم المساس بالبقية:** إقلاع الوحدة الثانية الدرس 1 والدرس 2 مع أزرار «السابق»/«التالي» ومؤشر التقدم، بوابة المعلم (رفض كلمة خاطئة، دخول بكلمة المرور المعتمدة، عشر مقالات صفحات، خروج)، وإقلاع اختبار الدرس.
- **اللقطات:** `student-*` (الخطوة الأولى)، `step-98/101/105/106-*` (خطوات متعددة لا الصفحة الأولى فقط)، `controls-*` (زرّا «السابق»/«التالي» ومؤشر التقدم وإعلان الخطوة)، `activities-*` (أسئلة ص105)، `labs-*` (مختبر ص101)، `complete-*`، `teacher-*` — لكل مقاس من المقاسات الثلاثة.

إعادة التشغيل:

```bash
npm run build
python3 -m http.server 4173 --bind 0.0.0.0 --directory dist
QA_MODULE_DIR=/path/to/qa/node_modules node scripts/qa-unit2-lesson3.mjs
```

## 1. السبب الجذري

كان التعطل ناتجًا عن خللين أدخلهما PR #47 في مسار تحميل الدرس الرابع:

1. **خطأ نحوي يمنع تنفيذ الصفحة كلها**
   في `src/unit2-lesson4-notebook.js`، بدءًا من السطر 35، وُضعت استدعاءات مثل `${tex('R', ...)}` داخل سلاسل JavaScript محددة بعلامات اقتباس مفردة. علامة الاقتباس قبل `R` كانت تنهي السلسلة، فيرفض المحلل الملف بـ:
   `SyntaxError: Unexpected identifier 'R'`.
   لأن `src/unit2-lesson4-main.js` يستورد الدفتر استيرادًا ثابتًا، كانت وحدة الدفتر تُحلّل قبل تنفيذ جسم ملف التهيئة. لذلك لم يصل التنفيذ إلى إنشاء `LessonStepper` أو أزرار `#page-nav` أو العرض الأول في `renderStep()`.

2. **دالة التنقل المحذوفة**
   حذف PR #47 تعريف `goToStep(index, moveFocus)` من `src/unit2-lesson4-main.js`، لكنه أبقى استدعاءاته في أزرار القائمة، السابق/التالي، زر البدء، لوحة المفاتيح و`hashchange`. بعد إصلاح الخطأ النحوي ظهرت في المتصفح:
   `ReferenceError: goToStep is not defined`.

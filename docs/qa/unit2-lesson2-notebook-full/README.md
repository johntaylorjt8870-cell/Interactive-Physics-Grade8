## تشغيله

```bash
# 1. خدمة المستودع على المنفذ 4173
python3 -m http.server 4173 --bind 0.0.0.0

# 2. بيئة المتصفح (لا تُخزَّن في المستودع)
mkdir -p /tmp/qaenv && cd /tmp/qaenv
npm i playwright-core @sparticuz/chromium
# مكتبات Chromium: فكّ حزمة al2023.tar.br إلى /tmp/nss ثم
export LD_LIBRARY_PATH=/tmp/nss/lib

# 3. التشغيل
cd /home/user/Interactive-Physics-Grade8
node docs/qa/unit2-lesson2-notebook-full/qa.mjs
```

## ما يفحصه

1. 11 تبويبًا في مسار الدرس، آخرها «دفتر الطالب»، والدفتر في المرحلة 11 (`11 / 11`).
2. دفتر واحد فقط بعد مغادرة المرحلة والعودة إليها.
3. 18 قسمًا، 24 جدولًا كلها معنونة، 7 أشكال هي صور `UNIT2L2_DIAGRAMS` نفسها.
4. 216–218 تعبير KaTeX وصفر `katex-error`، ولا قصّ لمعادلة عرض.
5. لا تمرير أفقي للصفحة، ولا خروج قسم عن الورقة، وكل جدول يتّسع أو يمرّر داخل غلافه.
6. 18 رابط فهرس تعمل، وأحدها يمرّر فعلًا إلى `#nb-s06`.
7. كل `<bdi>` بـ`dir="ltr"`، وصفر نصّ عربي داخل عزل لاتيني، وصفر تقاطع بين كتل عربية ولاتينية.
8. **صفر «قيمة + وحدة» عارية في نصّ عربي** — الفحص الذي كشف خلل «٢٠٠ mA» المرسوم «mA ٢٠٠».
9. صفر أخطاء console أو صفحة.

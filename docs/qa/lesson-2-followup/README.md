# تدقيق لاحق للدرس الثاني — رموز القوى، «اختر الإجابة»، والعمليات بسطر واحد

الفرع: `arena/f46c7c36-interactive-physics-grade8` (مبني على `main` عند `b5575c0`).
القياس: **1366×768** على Chromium حقيقي (headless 141 عبر `playwright-core` +
`@sparticuz/chromium` المثبّتين خارج المستودع)، مع تشغيل `npm test` و`npm run build`.
اللقطات هنا مأخوذة من بناء `dist/` الإنتاجي، لا من ملفات التطوير.

## الإصلاحات

- تصحيح 166 موضع TeX مضاعف الشرطة في ملفات الدرس الثاني الأربعة، فصارت `×` و`÷` و`\,` و`\mathrm{}` و`\dfrac{}` تُرسم فعلًا بلا فواصل أسطر.
- تحويل **سلاسل العمليات الحسابية** من الكسور المكدّسة إلى صيغة الشرطة المائلة بسطر واحد في محتوى الطالب ومنطقة المعلم وحلول الاختبار، مثل
  `\dfrac{50}{0.5}=\dfrac{20}{d_2}\Rightarrow d_2=0.2\,\mathrm m` →
  `50/0.5=20/d_2\;\Rightarrow\;d_2=0.2\,\mathrm m`، ودمج خطوتَي l2q12 وl2q20 في سطر واحد.
  أُبقيت علاقات التناسب والقوانين بصيغة `\dfrac` لأنها علاقات لا عمليات حسابية.
- إضافة `.force-plum` و`.force-slate` (لون الساق)، و`.sym-plum` و`.sym-slate` (لون الرمز)، و`.force-prime` إلى
  `src/styles.css`، وتوحيد `FORCE_PALETTE` في `src/diagrams.js` مع ألوان الـ CSS حتى يطابق رأس السهم ساقه.
- إصلاح `alignedSteps()` بحيث يفصل بين الصفوف بفاصل واحد بلا `&` زائدة.
- استبدال `formula()` بـ `tex()` في خيارات ص 70 الاثني عشر، وتوسيع مساحة النقر (`is-choice`) مع
  `role="radiogroup"` و`aria-labelledby` و`:focus-within` في `src/lesson-2.css`.
- وحدة جديدة `src/lesson-2-choice-state.js` تعيد استخدام مخفّضات الحالة النقية للدرس الأول بمفتاح تخزين
  مستقل (`physics8.lesson2.choice.v1`)؛ `src/lesson-2-practice.js` تستعيد الاختيار والنتيجة والتلميح عند كل إعادة عرض.

`jsdom` مثبّتة محليًا في `node_modules/` (مستبعدة من git) لتفعيل اختبارات DOM التي كانت تتخطى؛
في بيئة بدونها تتخطى اختبارات DOM تلقائيًا كما كان معتادًا. ثلاثة ملفات اختبار جديدة تحمي الإصلاحات:
`tests/force-symbols-and-math.test.js`، `tests/lesson-2-choices.test.js`،
`tests/lesson-2-math-and-areas.test.js`.
